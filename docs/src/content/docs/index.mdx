title: Overview
description: Persistently float selected Hyprland windows.
---

`float-app` identifies Hyprland windows and writes persistent floating rules for their exact class or initial class.

- **Pick a window.** Select any visible window with `slurp`, without changing keyboard focus.
- **Persistent rules.** Keep managed rules in a generated file and include it from your chosen Hyprland config.
- **Config-safe writes.** Preserve stowed symlinks, support Lua and conf configs, and avoid replacing Omarchy's shared floating rules.
